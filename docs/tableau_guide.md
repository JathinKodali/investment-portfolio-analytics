# Tableau Guide

Workbook: `tableau/Investment_Portfolio_Analytics.twbx` (opens in Tableau Desktop / Public Edition 2026.2).
It is generated by `tableau/build_workbook.py` from the CSV files in `data/tableau/`, so every setting below is also visible in that script.

## Data sources

| Tableau name | File | One row per |
|---|---|---|
| Market Data | `tableau_market_data.csv` | stock per trading day (2,622 rows) |
| Portfolio Allocation (Sample) | `tableau_portfolio_allocation.csv` | holding (6 rows, SAMPLE / DEMO DATA) |
| Portfolio Holdings (Sample) | `tableau_portfolio_holdings.csv` | holding, with current value and P/L (Phase 3) |
| Portfolio Summary | `tableau_portfolio_summary.csv` | one row of portfolio, risk and benchmark KPIs |
| Sector Exposure | `tableau_sector_exposure.csv` | sector (Phase 5) |
| Risk and Return | `tableau_risk_return.csv` | stock, plus one S&P 500 row (Phase 4) |
| Benchmark Comparison | `tableau_benchmark_comparison.csv` | date × series (Sample Portfolio, S&P 500), indexed to 100 (Phase 6) |
| Goal Simulator | `tableau_goal_scaffold.csv` | year (0–40) × series; holds only labels, the values are calculated from the parameters |
| Parameters | (none) | the 5 Goal Simulator inputs |

`tableau_goal_projection.csv` (the Python year-by-year table for the default inputs) is not used by the workbook; it is there to check the Tableau numbers against.

Units: `Daily_Return` and `Cumulative_Return` are **decimals** (0.025 = 2.5%) and are formatted as % in Tableau. `Price_Change_Percentage` is already a **percent number** (2.5 = 2.5%).

## Calculated fields

| Field | Formula | Why |
|---|---|---|
| Cumulative Return % (Selected Period) | `EXP(SUM(LN(1 + [Daily_Return]))) - 1` | Compounds the daily returns of the dates left after filtering. Tableau has no PRODUCT(), so `exp(sum(ln(1+r)))` is used; it equals `product(1+r)`. With all dates selected it matches the Python `Cumulative_Return`. |
| Stocks Tracked | `COUNTD([Ticker])` | KPI tile |
| Sectors Covered | `COUNTD([Sector])` | KPI tile |
| Trading Days | `COUNTD([Date])` | KPI tile |
| Date Range Label | first and last date as text | KPI tile |
| Return Rank (Best First / Worst First) | `RANK([Cumulative Return %], 'desc' / 'asc')`, computed along Company | Filtered to rank 1 to show the best / weakest stock |
| Share of Amount Invested | `SUM([Investment_Amount]) / MIN({FIXED : SUM([Investment_Amount])})` | Each holding's share of the total amount invested |
| Number of Holdings | `COUNTD([Ticker])` | KPI tile |

## Sheet 1 — Stock Price Trend (line chart)

- Columns: `Date` (continuous, exact date)
- Rows: `AVG(Close)`, axis titled "Closing price (USD)"
- Marks: Line; Color = `Ticker`; Label = `Ticker` at the line end
- Tooltip: Company, date, close, open/high/low, daily return, volume
- Filters: `Company` (multiple values) and `Date` (range of dates)

## Sheet 2 — Stock Return Comparison (bar chart)

- Rows: `Company`, sorted descending by the return
- Columns: `Cumulative Return % (Selected Period)`
- Marks: Bar; Color = `Ticker` (same colour as on the price chart); Label = return as `+0.0%`
- Uses the same Stock selection and Date filter, so moving the date slider recalculates every bar

## Sheet 3 — Portfolio Allocation (treemap)

- Marks: Square; Size = `SUM(Investment_Amount)`; Color = `Ticker`; Detail = `Company`
- Label: ticker, amount invested, share of the portfolio
- Shows where the SAMPLE / DEMO money was invested on the purchase date (not today's value, which is Phase 3)

## Dashboard 1: Market Overview (1366 × 768)

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Investment Portfolio & Market Analytics            (title + data notes)  │
├──────────┬──────────┬──────────────┬───────────────┬─────────────────────┤
│ Stocks   │ Trading  │ Best         │ Weakest       │ Sample portfolio    │
│ tracked  │ days     │ performer    │ performer     │ invested            │
├──────────┴──────────┴──────────────┴───────────────┼─────────────────────┤
│ Stock Price Trend                                  │ Stock (drop-down)   │
│                                                    │          Date range │
├─────────────────────────┬──────────────────────────┤ Ticker colour key   │
│ Stock Return Comparison │ Portfolio Allocation     │ About the data      │
└─────────────────────────┴──────────────────────────┴─────────────────────┘
```

Interactions:

- The **Stock** drop-down (a parameter: "All stocks" or one company) and the **Date** filter drive the price chart, the return bars and the first four KPI tiles. Each of those sheets filters on the calculated field `In Stock Selection = IIF([Stock] = 'All stocks' OR [Company] = [Stock], 'Yes', 'No')`.
- Why a parameter instead of a Company checklist: Tableau 2026.3 re-saves a shared categorical quick filter without its data-source name and then cannot reopen the workbook ("Field ... which is included for filtering does not exist"). Parameter-driven filters save and reopen cleanly.
- **Highlight action:** clicking any stock highlights the same ticker on every chart, including the treemap, which uses a different data source.
- Colours are fixed per ticker and were checked for colour-blind safety, so a stock keeps its colour when others are filtered out.

```text
└────────────────────────────────┴─────────────────────────────────────────┘
```

- **P/L by Holding:** Rows = Company (sorted by P/L); Columns = SUM(Profit_Loss); Colour = Ticker (same colours as the Market Overview); Label = P/L and return %.
- **Sector Exposure:** Rows = Sector; Columns = SUM(Sector_Weight), formatted as %.
- **Portfolio vs S&P 500:** Columns = Date; Rows = AVG(Index_Value); Colour = Series. Both lines start at 100 on 2 Jan 2025.
- **KPI tiles and Diversification card:** text sheets reading the one-row Portfolio Summary source.

## Dashboard 3: Risk & Return (Phase 4 + optional Phase 13)

- **Risk vs Return (scatter):** Columns = AVG(Annualized_Volatility); Rows = AVG(Annualized_Return); Detail and Label = Ticker; Colour = Risk_Group (Low green, Medium amber, High red, Benchmark grey). The colour legend sits under the chart.
- **Sharpe Ratio** and **Maximum Drawdown:** horizontal bars per company, sorted best first, using the same risk-group colours.
- **KPI tiles:** most / least volatile stock, best Sharpe ratio, deepest drawdown, S&P 500 volatility and drawdown.

## Dashboard 4: Goal Simulator (Phases 7–12)

Parameters (sliders in the left column):

| Parameter | Default | Range | Step |
|---|---|---|---|
| Initial Investment (₹) | 2,00,000 | 0 – 50,00,000 | 10,000 |
| Monthly Investment / SIP (₹) | 5,000 | 0 – 2,00,000 | 500 |
| Target Amount (₹) | 10,00,000 | 1,00,000 – 2,00,00,000 | 50,000 |
| Expected Annual Return (%) | 12 | 0 – 30 | 0.5 |
| Investment Period (years) | 5 | 1 – 40 | 1 |

Calculated fields (P, PMT, T, R, N = the parameters above; R is a percent):

| Field | Formula |
|---|---|
| FV of Initial (Year) | `P * POWER(1 + R/100, [Year])` |
| FV of SIP (Year) | `IIF(R = 0, PMT*12*[Year], PMT * (POWER(1 + R/1200, 12*[Year]) - 1) / (R/1200))` |
| Projected Value (Year) | FV of Initial (Year) + FV of SIP (Year) |
| Total Contributions (Year) | `P + PMT*12*[Year]` |
| Projection Amount | `CASE [Series]` → Projected Value (Year) / Total Contributions (Year) / T |
| In Investment Period | `IIF([Year] <= N, 'Yes', 'No')`: filter on the projection chart |
| Is Final Year | `IIF([Year] = N, 'Yes', 'No')`: filter on the Goal Progress bars |
| Projected Portfolio Value | the same formula at year N |
| Required Monthly Investment | `IIF(T - P*(1+R/100)^N <= 0, 0, (T - P*(1+R/100)^N) / SIP factor)` |
| Goal Gap | `T - Projected Portfolio Value` (format shows "short" or "surplus") |
| Goal Achievement % | `Projected Portfolio Value / T` |
| Goal Status | `IIF(Projected >= T, 'Goal achieved', 'Not yet achieved')` |

- **Portfolio Growth Projection:** Columns = Year (continuous); Rows = SUM(Projection Amount); Colour = Series. The red Target line plays the part of a reference line.
- **Goal Progress:** bars for Projected Value, Total Contributions and Target in the final year.
- With the defaults the tiles should show ₹7,60,817 projected, ₹7,929 required SIP, ₹2,39,183 short and 76.1%, the same as `python main.py`.

Note: Tableau formats numbers with Western digit grouping (₹1,000,000). Indian grouping (₹10,00,000) isn't available in a number format.

## Refreshing after new data

```bash
python main.py --download
python tableau/build_workbook.py
```

Re-running `build_workbook.py` overwrites the workbook. `main.py --download` also refreshes the S&P 500 file `data/raw/benchmark_raw.csv`. If you make manual changes in Tableau, use **File → Save As** with a new name first.
